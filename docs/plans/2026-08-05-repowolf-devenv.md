# RepoWolf Devenv Dogfood Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an automatically activated devenv shell that exposes RepoWolf's two local flake packages alongside the existing Go release toolchain.

**Architecture:** Devenv consumes this repository as a relative Git flake input using `git+file:.?ref=HEAD`, then selects the public `repowolf` and `repowolf-client` package outputs for the active Linux system. A committed `.envrc` activates the locked environment through direnv, while ignored local state stays outside version control and the existing flake devShell remains unchanged.

**Tech Stack:** Nix Flakes, devenv 2.x, direnv, Go, GoReleaser, Skopeo

## Global Constraints

- Expose `go`, `goreleaser`, `skopeo`, `repowolf`, and `repowolf-client`.
- Consume RepoWolf through `git+file:.?ref=HEAD`; do not recreate packages with `callPackage` or pin this repository through GitHub.
- Select `inputs.repowolf.packages.${pkgs.stdenv.system}.repowolf` and `inputs.repowolf.packages.${pkgs.stdenv.system}."repowolf-client"`.
- Keep the existing `flake.nix` `devShells` output unchanged.
- Add no service process, policy, TLS, token, provider credential, shell secret, mutable install fallback, git hook, or background orchestration.
- Preserve `.worktrees/` in `.gitignore`; explicitly re-include the committed `.envrc` over user-level Git excludes, then add only devenv/direnv generated-state rules.
- Commit `devenv.lock`; never commit `.devenv*`, `.direnv`, `devenv.local.nix`, or `devenv.local.yaml`.
- RepoWolf package outputs support `x86_64-linux` and `aarch64-linux`; do not claim Darwin support.
- Testing Value Gate: this is static development-environment configuration. Do not add an automated test that restates file contents; prove behavior through real evaluation, package execution, direnv activation, and the existing full flake check.

**Interfaces:**
- Consumes: `flake.nix` package outputs `packages.${system}.repowolf` and `packages.${system}."repowolf-client"`.
- Produces: automatic `direnv` activation and manual `devenv shell` access to `go`, `goreleaser`, `skopeo`, `repowolf`, `repowolf-client`, `gh`, and `repowolf-git-ssh`.

- [ ] **Step 2: Create the activation and input files**

Create `.envrc`:

```bash
eval "$(devenv direnvrc)"

```

Replace `.gitignore` with:

```gitignore
.worktrees/

# Devenv
.devenv*
devenv.local.nix
devenv.local.yaml

# direnv
!.envrc
.direnv
```

Create `devenv.yaml`:

```yaml
# yaml-language-server: $schema=https://devenv.sh/devenv.schema.json
inputs:
  nixpkgs:
    url: github:cachix/devenv-nixpkgs/rolling
  repowolf:
    url: git+file:.?ref=HEAD
```

- [ ] **Step 3: Create the environment module**

Create `devenv.nix`:

```nix
{ inputs, pkgs, ... }:

let
  repowolfPackages = inputs.repowolf.packages.${pkgs.stdenv.system};
in
{
  packages = [
    pkgs.go
    pkgs.goreleaser
    pkgs.skopeo
    repowolfPackages.repowolf
    repowolfPackages."repowolf-client"
  ];
}
```

- [ ] **Step 5: Generate and inspect the lock file**

Run:

```bash

jq -e '
  .nodes.repowolf.original.type == "git" and
  .nodes.repowolf.original.url == "file:." and
  .nodes.repowolf.original.ref == "HEAD" and
  .nodes.repowolf.locked.type == "git" and
  .nodes.repowolf.locked.url == "file:." and
  .nodes.repowolf.locked.ref == "HEAD"
' devenv.lock
! grep -F 'feat/dogfood-devenv' devenv.lock
```

Expected: devenv evaluation exits 0, `devenv.lock` is non-empty, the local input is locked to the branch-neutral `HEAD` reference, and no task branch name appears.

- [ ] **Step 6: Prove every tool and both RepoWolf package outputs work**

Run:

```bash
devenv shell -- bash -euc '
  for command in go goreleaser skopeo repowolf repowolf-client gh repowolf-git-ssh; do
    command -v "$command" >/dev/null
  done

  test "$(repowolf --version)" = "dev"
  repowolf-git-ssh -G git@github.com

  clientBinary=$(readlink -f "$(command -v repowolf-client)")
  test "$(readlink -f "$(command -v gh)")" = "$clientBinary"
  test "$(readlink -f "$(command -v repowolf-git-ssh)")" = "$clientBinary"

  go version | grep -q "^go version "
  goreleaser --version >/dev/null
  skopeo --version | grep -q "^skopeo version "
'
```

Expected: exit 0. The server reports version `dev`; the credential-free SSH capability probe succeeds without output; both restricted client links resolve to the packaged `repowolf-client` binary; all development tools execute.
